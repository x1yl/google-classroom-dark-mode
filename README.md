# Google Classroom Dark Mode Extension

A simple browser extension that adds a dark mode toggle button to Google Classroom. Easy on the eyes, fully customizable, and remembers your preference.

## Features

- Toggle between light and dark mode
- Remembers your preference
- Carefully designed dark theme
- Responsive design
- Lightweight and fast

## Installation

### Chrome Installation
1. Go to the [Releases](https://github.com/x1yl/google-classroom-dark-mode/releases) page
2. Download the latest `.crx` file
3. Open Chrome and navigate to `chrome://extensions/`
4. Enable "Developer Mode" in the top right
5. Drag and drop the downloaded `.crx` file into the extensions page

### Firefox Installation
#### Regular Installation (Recommended)
1. Visit the [Firefox Add-ons Store](https://addons.mozilla.org/en-US/firefox/addon/dark-mode-for-google-classroom/)
2. Click "Add to Firefox"
3. Follow the prompts to complete installation

#### Advanced Installation (Developer Version)
1. Go to the [Releases](https://github.com/yourusername/google-classroom-dark-mode/releases) page
2. Download the latest `.zip` file
3. Navigate to `about:debugging#/runtime/this-firefox`
4. Click "Load Temporary Add-on"
5. Select the downloaded `.zip` file

Note: The advanced installation method is only recommended for development and testing purposes.
Note 2: Manual installations will not get updates, please check back to install the latest versions.

## Usage

After installation, you'll see a toggle button in the bottom right corner of Google Classroom. Click it to switch between dark and light modes.
